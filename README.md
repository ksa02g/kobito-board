# 小人の黒板（kobito-board）

ブラウザの中の黒板です。チョークで線を描くと、**その線がそのまま小人たちの足場になり**、
小人たちは**左から右へ**歩いていきます。線は時間がたつと順に消えていきます。

奈良健康ランド「はしゃキッズ」のような、壁面インタラクティブのイメージで作っています。

- ファイルは **`index.html` 1つだけ**（ライブラリ・ビルド・通信すべて不要）
- 完全オフライン動作
- PC・スマホ・タブレット共通。タッチでそのまま描けます
- **マルチタッチ対応** — 何人でも同時に描けます（指ごとに別の線として扱います）
- **BGM つき** — 音源ファイルを持たず、その場で音を合成しています

## 世界のしくみ

### 線は消えていきます

| 対象 | 寿命 | 消えかた |
|---|---|---|
| あなたが描いた線 | **20秒**（つまみで5〜90秒に変更可） | 描きはじめた端から順に、食べられるように消えていく |
| 小人が自分で描いた落書き | **60秒**（描き終えてから計測） | 同上 |
| 草花 | 20〜75秒 | 生えて、育って、枯れてしぼんで消える |
| つる・はしご | 45〜150秒 | 伸びて、しばらく立って、しぼんで消える |
| いちばん下の地面 | 消えません | — |

線が消えると、その上に乗っていた小人は落ちます。落ちきった小人は空から降りなおします。

### 草花

地面から草・花・双葉がひとりでに生えて、育って、しばらくすると枯れて消えます。
**描いた線の上にも生え**（約3回に1回）、その線が消えると草花もいっしょに枯れます。
雨のあいだは、生えるのも育つのも速くなります。

### 小人（5〜20人）

人数は5〜20人のあいだでランダムに変動します。画面の左（または空）から現れ、右へ歩いて退場します。

| ふるまい | 内容 |
|---|---|
| 歩く | 描かれた線の上を右へ。傾いた線は坂として登り降りする |
| よじ登る | 身長の半分くらいまでの段差はひょいと乗り越える |
| 飛ぶ | 線が途切れた崖ではジャンプするか、少し引き返してから再挑戦する |
| 落ちる | 足場が消える・消されると落下する |
| 休む | 座る・寝る・伸びをする・よろこぶ・ひとりごと |
| 落書き | ときどき自分でチョークを持ち、ハート・星・うずまき・花・魚・家を描く。**それも足場になり、60秒で消える** |

### タップ（クリック）すると反応します

| 対象 | 反応 |
|---|---|
| ☀ **太陽** | ぱっと光り、光の粒が飛び、画面全体がまぶしくなる。小人たちがいっせいによろこぶ。消灯中にタップすると点灯する |
| ☁ **雲** | 雨が降る。雨粒は地面や描いた線にあたって跳ねる。小人が「あめだ！」と言う。やんだあと、たまに**虹**が出る。雨のあいだ草花が育つ |
| 🫧 **シャボン玉** | **割れて、中身が出てくる**（下表） |
| 🐦 **小鳥** | **つかまえられる**（下記）。ふだんは空を飛び、ときどき**描いた線の上にとまる**（その線が消えると飛び立つ） |
| 🚶 **小人** | びっくりしてジャンプする |

### シャボン玉の中身

地面からゆっくり浮かびあがってきます。タップして割ると、中に入っていたものが出てきます。

| 中身 | 割ると |
|---|---|
| **まめのたね** | たねが地面に落ちると、そこから**ジャックと豆の木がぐんぐん伸びます**（小人が登れます） |
| 小人 | **仲間がひとり増えます**（その場から落ちてきて歩きはじめる） |
| 小鳥 | 一羽増えて、その場から飛び立つ |
| 星 | きらめきをまき散らして昇っていく |
| 音符 | ♪ が舞う |
| 魚 | 空を泳いで消えていく |
| ハート | ふわりと昇って消える |

割らずに放っておくと、天井まで昇って自然にはじけます（中身は出ません）。

### つる（豆の木）と はしご — 小人が登ります

**はしご**はときどきひとりでに現れます。
**豆の木は、シャボン玉から出たまめのたねが地面に落ちたときだけ生えます。**

- 小人は近くを通りかかると**よじ登ります**。登り降りの途中で気が変わることもあります
- てっぺんは**葉っぱ／踏み板の足場**になっていて、登りきった小人はよろこびます。
  そのあと降りたり、足場から落ちたりします
- つるもはしごも寿命があり、消えます。**登っている途中で消えると小人は落ちます**
- 雨が降るとつるの伸びが速くなります

### 小鳥をつかまえる — ふたとおり

**① チョークで囲む**
小鳥は**チョークの線にぶつかります**。まわりをぐるりと囲って線でふさぐと、中から出られなくなり、
かごの中をばたばた飛びまわります。**すきまがあると逃げます。**
線が寿命で消えたり、黒板消しで穴をあけると ♪ を鳴らして飛び立ちます。
小人たちも「とじこめた！」「だしてあげて」と反応します。

**② 指でつまむ**
小鳥を押さえたまま指を動かすと、つかんだまま運べます。ばたばた暴れて ♪ をこぼします。

- **線や地面の上ではなす** → そこにとまります
- **空中ではなす** → 飛んでいきます
- **ちょんと触っただけ** → おどろいて飛び立ちます

## 遊びかたのヒント

- **右上がりの階段を描く** → 小人が次々に登っていきます
- **少し離した2本の橋** → ジャンプで渡ろうとします
- **雲の下に屋根を描く** → 雨が屋根で跳ねます
- **高い所に横線を描く** → 小鳥がとまりに来ます
- **足場を消してみる** → 上の小人が落ちます
- 線が消える設定を**5秒**にすると、描いても描いても足りない、にぎやかな遊びになります
- 展示に使うときは <kbd>H</kbd> で道具を隠し、ブラウザを全画面（<kbd>F11</kbd>）に

## 動かしかた

### いちばん簡単

`index.html` をダブルクリックしてブラウザで開くだけ。

### スマホ・タブレットで見る（同じ Wi-Fi の PC から）

```powershell
py -3 -m http.server 8000        # Mac/Linux なら python3 -m http.server 8000
ipconfig                          # IPv4 アドレスを確認（例 192.168.1.23）
```

スマホのブラウザで `http://192.168.1.23:8000/` を開きます。

### GitHub Pages で公開する（`moon-navi` と同じやり方）

GitHub 側で空のリポジトリ `kobito-board` を作ってから:

```powershell
cd "kobito-board"
git init
git add .
git commit -m "小人の黒板"
git branch -M main
git remote add origin https://github.com/ksa02g/kobito-board.git
git push -u origin main
```

そのあと GitHub のリポジトリで **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`** を選んで保存。
数十秒で `https://ksa02g.github.io/kobito-board/` に公開されます。

## BGM

やわらかい環境音楽が流れます。**音源ファイルは1つも持っていません。**
Web Audio API で、その場で音を合成しています。

- 音階は**ペンタトニック**（黒鍵だけのような音階）に限っているので、どの音が重なっても濁りません
- 8〜14秒かけてゆっくり立ち上がって消える音を、3〜7秒おきにランダムに重ねていきます
- 低いドローン（土台の音）＋人工リバーブ＋ゆっくり呼吸するフィルタで、奥行きを出しています
- **同じ旋律はくり返しません**（毎回その場で選んでいるため、ループ感がありません）
- 消灯すると、音も少し暗く・ゆっくりになります
- ブラウザの決まりで、**最初に画面をさわった時点から**鳴りはじめます

## しくみ（かんたんに）

- **線は1本ずつ独立したオブジェクト**です。1本ごとに自分専用の小さな canvas を持ち（描きながら
  必要なぶんだけ広げます）、寿命・透明度・「どこまで消えたか」を各自が持ちます。
  だから1本ずつ順に消せますし、**何本の線が同時に描かれていても混ざりません**（マルチタッチ）。
- 当たり判定は **3px 格子の被覆カウンタ**（`Uint16Array`）。線を引くとセルの数が増え、
  線が消えるとその線の分だけ減ります。重なった線を1本消しても、残りの線の足場は残ります。
- 消えていくときは、線の**通った順路をたどって先端から削っていく**ので、
  「描いた端から吸い取られる」ように見えます。削られた部分は当たり判定からも同時に外れます。
- 太陽・雲・小鳥は起動時に小さな画像として一度だけ描いておき、毎フレームは貼るだけにしています
  （チョークの粒がちらつかず、数が増えても軽い）。
- チョークの質感は、薄い線＋ランダムな粒の重ねがけで表現しています。
